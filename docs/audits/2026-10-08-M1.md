## Medium
- **Email sign-in only reaches the builder.** Supabase's built-in SMTP only delivers to project team members (about 2/hour). Classmates need the Resend sender domain (open item, SPEC §17) or Google sign-in. Fix before M2's friendly alpha.

## Low / polish

- `rooms.owner_id` cascades on profile delete; correct for personal rooms only. M2 must add the ownership-transfer rule (SPEC §7) before shared rooms exist.
- Precache is ~790 KB (supabase-js). Check again in the M4 performance pass.
