## High (all fixed)

1. **Changing your timezone reset the 720/day coin cap.**
   - **Evidence:** `profiles.tz` was client-writable. Live test: cap full, `update profiles set tz='EST5EDT'`, and the next note paid 59 more.
   - **Fix:** `revoke update (tz)`; the timezone is set once at signup (decision 0012). pgTAP 10 checks it.
2. **Saved layouts could carry hidden free text between members, up to 1.5 MB.**
   - **Evidence:** `layout_error` ignored extra keys and `save_layout` stored the caller's JSON as-is. Live test: `"msg": "text me …"` came back through `visit_room` and `room_info`.
   - **Fix:**
     - refuse unknown keys;
     - store a rebuilt `{item_id, x, z, rot}` array;
     - add a `rooms_layout_size` check (< 16 KB);
     - rate-limit saves (20 per 10 min).
   - pgTAP 10 covers all four.
3. **Lock-screen controls and background audio could not work.**
   - **Evidence:** the noise stations played only through an `AudioBufferSourceNode`, and Media Session attaches to media elements.
   - **Fix:** all audio now goes through a hidden `<audio>` element fed by a MediaStream, falling back to the speakers if the element is refused (decision 0013). Confirming it needs a real device (builder check).

## Medium (all fixed)

- **Overturning an unfair void didn't give the coins back.** `sessions_coin_effects` now handles `voided → completed` for both the wallet and the bank. pgTAP 10 covers it.
- **The first Play froze the main thread for about 200 ms or more** while the noise was synthesised. Noise is now made in a Web Worker as soon as the room opens.
- **Playlist sync tolerance was too loose for the 1 s target.** It is now 0.35 s, checked every 2 s, and seeks only after `loadedmetadata`.
- **Opening the app offline showed the raw "Failed to fetch" error page.** There is now an offline variant, and it retries on its own when the connection comes back.
- **Furniture could only be placed with a pointer.** In the editor, arrow keys now move the item, R turns it and Enter places it. There is an e2e test.
- **The room bank's 360-per-member cap had no test.** pgTAP 10 adds one.

## Low

**Fixed:**
- buying an accessory twice at once (the ownership check now runs under the coin lock);
- huge coordinates raising `integer out of range` (now `invalid_layout`);
- the export was missing room-bank contributions and the session behind each coin row;
- privacy page lines for keeping inventory and layouts, for coins left in a room bank after you leave, and for radio preferences kept on the device;
- the room timezone now falls back to UTC in the bank trigger;
- a negative room bank showed as "-90 coins" (it now shows 0);
- the Vercel rewrite now excludes `splash/` and `og-image.png`;
- a stale comment and a stale decision record (prices, catalog shape, voids count toward the daily cap);
- a unit test now checks track sources are on Supabase Storage (the CSP's `media-src`);
- the AudioContext is now suspended when idle.

**Accepted:**
- `set_room` station changes aren't rate-limited. Only owners and mods can make them, and a change only makes members refetch.
- `og:image` is a relative URL. An absolute one needs the final domain, which is a builder item.

## Earlier M7 fixes (same day, before this audit)

**Error-state survey.** Fixes for every call that could:
- show a false empty state ("no rooms", "0 coins", "not found");
- sign you out after a failed account deletion;
- open the shared-room editor on a failed load, so that saving would overwrite the room;
- update block state without the server agreeing.

**Accessibility pass:**
- dialogs can always be closed;
- a skip link;
- arrow keys in every tab list and radio group;
- no per-second announcements;
- busy states on actions that spend coins;
- confirmations before transferring ownership or making a new invite link;
- long text wraps;
- accessible names on status dots and reactions.

## Verified ✅ (abridged)

- **RLS:** on for every public table. Every security definer function pins `search_path`. Grants on the new tables are SELECT only, and own-row or member-row where that applies.
- **Direct writes refused:** coins, inventory, room inventory, layout, bank and `private.balance` all refuse direct writes or calls.
- **Coins:**
  - `submit_note` pays once, under a per-user lock, and only for completed sessions in the last 24 h.
  - `buy_item`, `donate` and `room_buy_item` validate amounts, roles and balances under locks.
  - Voids reverse exactly what was paid.
- **Account deletion:** a scan of every uuid/text/jsonb column after `delete_my_account` found only the day-long rate-limit keys.
- **Visiting** needs a shared room, no block in either direction, and an active-consent target.
- **No secrets in `dist/` or `src/`.** The service worker caches no API responses, and splash and OG images aren't precached.
- **CSP:** `img-src data:` covers the shop thumbnails; `media-src` covers Storage tracks.
- **No new third-party domains.** Fonts are self-hosted.
